# Titanic Survival Prediction 🚢⚓

A machine learning project using the classic [Titanic dataset](https://www.kaggle.com/c/titanic).
The goal is to predict passenger survival using logistic regression.

---

## 📂 Project Structure
titanic-ml/
│── data/ # raw CSVs from Kaggle
│── notebooks/ # optional Jupyter notebooks
│── submission/ # generated predictions for Kaggle
│── requirements.txt # dependencies
│── README.md # project overview
