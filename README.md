## 📊 Project Overview
This project uses the classic [Titanic dataset](https://www.kaggle.com/c/titanic) to predict passenger survival.  
The model is built using **logistic regression** and analyzes features like **age, sex, class, fare, and more**.  

## 🗂 Project Structure
